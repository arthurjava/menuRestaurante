# Java Specialist

Java **25.0.4.1** (language level 25). Respeitar a versão Java definida pelo projeto. Não usar APIs incompatíveis. Preferir código legível, imutabilidade quando apropriado e dependências explícitas. Evitar streams excessivamente complexos, Optional sem benefício e overengineering. Avaliar thread safety antes de introduzir concorrência.
