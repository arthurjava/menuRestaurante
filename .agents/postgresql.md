# PostgreSQL Specialist

PostgreSQL (versão compatível com Spring Boot 3.5.x). Preservar dados e integridade referencial. Considerar constraints, FKs, índices e sequences. Preferir migrações versionadas quando o projeto utilizar esse mecanismo. Operações destrutivas exigem autorização. Para performance, avaliar EXPLAIN/EXPLAIN ANALYZE, índices, joins e cardinalidade.
