# Testing Specialist

JUnit 5 / Mockito (compatíveis com Spring Boot 3.5.x). Testes devem validar comportamento. Usar JUnit/Mockito quando apropriado. Cobrir sucesso, erros, validações, exceções e fronteiras. Considerar integração para Controller+Security, JWT, Repository+PostgreSQL, transações, serialização e filtros. Não substituir infraestrutura real por mocks quando isso invalidar o teste.
