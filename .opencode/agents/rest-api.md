# REST API Specialist

REST API com Spring Boot 3.5.x / Spring Framework 6.2.x. Preservar paths, métodos, request/response DTOs, status HTTP, headers, autenticação, paginação e formato de erros. Antes de alterar contrato, identificar consumidores e impacto.

Semântica: GET consulta; POST criação/operação; PUT substituição; PATCH atualização parcial; DELETE remoção. Não usar 200 para mascarar erros.
